# Logistics Delivery Performance Analysis and Optimization

This four-week educational project covers strategic planning, data preprocessing, EDA, and predictive modeling.

**Data disclaimer:** Included CSVs are simulated synthetic data, not real company records. All example metrics and model scores are computed from this synthetic dataset and must not be represented as real-world measurements.

## Files
- `simulated_logistics_shipments_raw.csv`: synthetic data with deliberate missing values, duplicates, and extreme cost values.
- `simulated_logistics_shipments_clean.csv`: cleaned dataset used for analysis.
- Four weekly Word reports.
- `preprocessing_pipeline.py`, `eda_analysis.py`, `predictive_modeling.py`.
- `charts/`: charts embedded in Week 3 report.

## Dependencies
`pip install pandas numpy matplotlib seaborn scikit-learn python-docx`
